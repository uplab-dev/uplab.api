# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Обязательные правила

- **Синхронизация документации.** При любом изменении поведения API (эндпоинты, параметры, значения по умолчанию, фильтры/права, формат ответа, события) ОБЯЗАТЕЛЬНО обновлять оба источника документации: `README.md` и встроенную документацию `lib/Admin/Docs.php` (раздел админки «Сервисы → API Документация»). Держать их согласованными.
- **Синхронизация тестов.** При изменении эндпоинтов/параметров/формата ответа ОБЯЗАТЕЛЬНО обновлять тестовую коллекцию `tests/uplab.api.postman_collection.json` (Postman/Insomnia): добавлять новые запросы и приводить проверки (`pm.test`) в соответствие новому поведению. PR без синхронизации тестов считается неполным наравне с документацией.
- **Версионирование.** При изменениях поднимать версию в `install/version.php` и добавлять секцию в `CHANGELOG.md` (см. раздел «Версионирование и релизы» в README). Теги релизов — только аннотированные.
